# Test Cases

## Test Cases page

Reached by clicking "Test Cases" in the top navigation menu. No login is required.

- The page opens headed "Test Cases" and lists the test cases the site supports, each title rendered as a clickable link.
- Clicking a test case's title shows that test case's steps underneath its title, in place: no navigation away, the page remains the Test Cases page.
- The page has a "Feedback for Us" section showing a "Contact us" link that opens the Contact Us page in the same browser tab.
- The Test Cases page can also be reached by clicking the "Test Cases" button on the home page, which navigates away from the home page to the Test Cases page.
