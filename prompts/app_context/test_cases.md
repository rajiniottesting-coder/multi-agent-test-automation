# Test Cases

## Test Cases page

Reached by clicking "Test Cases" in the top navigation menu. This opens the Test Cases page, headed "Test Cases". No sign-in is required for this page.

- The page lists the test cases, each title rendered as a clickable link.
- Clicking a test case title reveals that test case's steps in place, directly underneath its title; the page does not navigate away and the URL still points to the Test Cases page.
- Each title reveals its own steps independently: clicking a second title shows that one's steps without leaving the page.
- The page has a "Feedback for Us" section, shown lower down, displaying an email address to write to.
- When a scenario needs a specific entry and the story names none, reach it by position ("the first test case title", "the second test case title"), not by a guessed title.
