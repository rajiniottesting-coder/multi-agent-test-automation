# Test Cases

## Test Cases page

Reached by clicking "Test Cases" in the top navigation. The page opens headed "Test Cases" and is available without signing in.

- The page lists the test cases, with each test case's title rendered as a clickable link.
- Clicking a test case's title reveals that test case's steps underneath its title, in place: no navigation occurs and the page stays on the Test Cases page.
- Each title acts independently - clicking a second test case's title reveals its own steps underneath it, and the page still does not navigate away.
- The page shows a "Feedback for Us" section, further down, displaying an email address to write to.
- When a scenario needs test cases by position rather than by name, reach them as "the first test case" and "the second test case" - the notes record no fixed titles here.
