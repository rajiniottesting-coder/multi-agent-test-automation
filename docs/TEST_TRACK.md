# Test track: live checks still open

Every change is first proven offline (unit tests, a fake Jira and repository
host, deliberate breaks). This file tracks the second half: **the live check
of each change against the real Jira, GitHub Actions, the model gateway and
the application under test.**

The validation of November 2026 proved 254 of 271 checks live. Those rows,
their runbook and the map of every merged change to its proof are kept in git
history: `git show 7b663cf:docs/TEST_TRACK.md`. This file keeps only what is
still open, and the rows each new change adds.

**Rules**

1. Every backlog item ([BACKLOG.md](./BACKLOG.md)) or fix adds its rows here
   when it is built: status ⬜, the PR and item ID in *Built in*. A unit test
   (`tests/unit/test_test_track.py`) fails when an item marked *Done* in the
   backlog has no row.
2. Before a run, read each row's expected result; change it first if it no
   longer matches the design - never after the run.
3. Record the result in the row: ✅ with the date and evidence (run link,
   issue key, PR number), or ❌ with the backlog item opened for it. A row with
   sub-checks passes only when all of them pass. A row proven ✅ is removed in
   the next evidence PR (its PR keeps the history).
4. Status: ⬜ open or partly proven, ❌ failed (replaced by the row named in
   its evidence), ➖ not applicable.
